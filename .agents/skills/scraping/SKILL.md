# Hub Master de Web Scraping & Engenharia de Dados

Centraliza as melhores ferramentas para coleta automatizada, raspagem indetectável, evasão de Cloudflare/anti-bots e estruturação de dados.

---

## Ferramentas Integradas:

1. **/scrapling-official**:
   - Framework Python ultra-rápido de web scraping indetectável (bypassa Cloudflare, DataDome, Akamai sem overhead de browser pesado quando desnecessário).

2. **Firecrawl (`firecrawl:*`)**:
   - Conversão de sites inteiros em Markdown limpo, crawl de domínios profundos e extração estruturada de conteúdo para LLMs/RAG.

3. **Bright Data (`brightdata-plugin:*`)**:
   - Proxies residenciais globais, desbloqueio de páginas protegidas, SERP scraping e datasets estruturados.

4. **/db-documentar**:
   - Mapeamento, documentação de tabelas, relacionamentos e schemas de bancos de dados.

5. **/seo-aeo-geo**:
   - Auditoria de posicionamento e visibilidade orgânica para buscadores tradicionais e modelos generativos (GEO).
